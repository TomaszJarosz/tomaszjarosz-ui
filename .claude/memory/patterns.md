# Patterns

Lessons learned z pracy z tomaszjarosz-ui.

---

## Format wpisu

```markdown
## [DATA] - [Tytuł]

**Kontekst**: [Co robiłem]
**Problem**: [Co poszło nie tak]
**Rozwiązanie**: [Jak naprawiono]
**Package**: [który pakiet]
```
